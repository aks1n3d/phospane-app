# Phospane

Website and downloads for **Phospane**, a low-latency remote desktop for Mac and Windows.

- Website: GitHub Pages from this repo (`index.html`, no build step).
- Downloads and the in-app update feed: [Releases](https://github.com/aks1n3d/phospane-app/releases).
  Each release has `phospane-macos.dmg`, `phospane-windows-setup.exe`, the updater files with their
  signatures, and `latest.json`, which installed copies of Phospane check for updates.

Releases are published from Phospane's private source repo with `app/scripts/release.mjs`.
