# beam

Website and downloads for **beam**, a low-latency remote desktop for Mac and Windows.

- Website: GitHub Pages from this repo (`index.html`, no build step).
- Downloads and the in-app update feed: [Releases](https://github.com/aks1n3d/beam-app/releases).
  Each release has `phospane-macos.dmg`, `phospane-windows-setup.exe`, the updater files with their
  signatures, and `latest.json`, which installed copies of beam check for updates.

Releases are published from beam's (private) source repo with `app/scripts/release.mjs`.
